# guessing-game-Tabeerkamran

## Description
This is a Number Guessing Game made in Python.
The computer randomly selects a number and the player has to guess it.

## Difficulty Levels
- **Easy**: Guess between 1-50 with 10 attempts
- **Medium**: Guess between 1-100 with 7 attempts  
- **Hard**: Guess between 1-500 with 5 attempts

The game gives hints: "Too High" or "Too Low" after each guess.

## How to Run
1. Make sure Python 3 is installed
2. Open terminal or command prompt
3. Run the command:
   python guessing_game.py
4. Choose a level and start playing!
